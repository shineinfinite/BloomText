# BloomText — Cute Anime-Inspired Text Studio

This is a static website. It does **not** use npm, frameworks, API keys, or external JavaScript libraries.

## Files
- `index.html` — page structure
- `style.css` — styling, colours, responsive layout, and subtle motion
- `script.js` — text generator, kaomoji, emoji combinations, symbols, and copy buttons

## Publish on GitHub Pages
1. Open your **BloomText** repository.
2. Upload these three files to the repository's top level (not inside another folder).
3. If GitHub asks whether to replace existing files, choose **Commit changes**.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/(root)`, then Save.
7. Wait for the Pages deployment to finish.

Because this is a project repository named `BloomText`, the expected website address is:
`https://shineinfinite.github.io/BloomText/`

If your repository is instead named exactly `shineinfinite.github.io`, its address is `https://shineinfinite.github.io/`.

## Important
- Keep all three files together in the repository root.
- File names are case-sensitive: `index.html`, `style.css`, and `script.js`.
- After uploading changes, refresh the website. If an old version remains, hard-refresh or clear the browser cache.
- No separate library installation is needed.
