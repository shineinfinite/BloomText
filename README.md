# Cute Text Studio

## Features
- Subtle motion and scroll-reveal effects (respects reduced-motion settings)
- Self-contained floral SVG background illustrations; no separate image downloads required
- 100+ generated copy-and-paste text styles (Unicode styles and decorative variations)
- Search and category filters for text styles
- 70+ kaomoji / text emoticons across moods
- 100+ emoji and aesthetic combos
- 100+ copyable decorative symbols
- Mini bio composer with character counter and copy button
- Responsive mobile layout and copy-to-clipboard buttons

## Notes
- This is a front-end-only static site. It does not collect visitor data or need a server.
