# BloomText — Cute Text Studio

A responsive, static website made with plain HTML, CSS and JavaScript. No build tools, frameworks, API keys, database or sign-up required.

## Features
- Subtle motion and scroll-reveal effects (respects reduced-motion settings)
- Self-contained floral SVG background illustrations; no separate image downloads required
- 100+ generated copy-and-paste text styles (Unicode styles and decorative variations)
- Search and category filters for text styles
- 70+ kaomoji / text emoticons across moods
- 100+ emoji and aesthetic combos
- 100+ copyable decorative symbols
- Mini bio composer with character counter and copy button
- Responsive mobile layout and copy-to-clipboard buttons

## Publish with GitHub Pages
1. Create a new public repository on GitHub.
2. Upload **index.html**, **style.css**, **script.js**, and **README.md** to the repository root.
3. Open repository **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. Wait for the Pages deployment and open the URL shown there.

GitHub's official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Notes
- This is a front-end-only static site. It does not collect visitor data or need a server.
- Fancy text is created with Unicode characters, not actual downloadable font files. Some characters may look different or unsupported on certain devices/apps.
- Google Fonts is an optional visual enhancement; the site falls back to system fonts if it cannot load.
- The included tool content is original and does not copy the referenced websites' code or branding.
- Before choosing a hosting provider for an ad-supported/commercial project, check that provider's current terms. GitHub Pages has restrictions on commercial use: https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits
